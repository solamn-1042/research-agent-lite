## 进一步追问的训练点

| 主题 | 本项目训练方式 | 交付 |
| --- | --- | --- |
| 项目讲解与完整架构 | D1给出输入到搜索结果的路径，D2补图与State，D7形成三个时长的介绍 | 业务复盘表、架构图、可解释Trace |
| 方案决策 | 比较固定流程/局部Agent，单/多Agent，直接API/网关，SQLite/独立存储 | 至少两个含备选方案、代价、验证和替换条件的决策记录 |
| RAG细节 | 分块、增量重建、向量/关键词、Top-K与阈值、版本与访问范围；说明是否需要Reranker | 实际检索片段与独立检索/生成评价 |
| 工具与协议 | 模型生成参数、本地执行器、MCP发现/调用分别观察 | 调用记录、Schema、服务端校验 |
| 模型选型 | 用可配置DeepSeek建立基线；可选第二模型按同一小样本对照，未测则留空 | 成功率、延迟、Token、价格来源与日期 |
| 可靠性 | 最大步数、无进展、临时错误与确定性错误、必要依赖失败、保存结果未知 | 故障分类、有限重试、状态核对与回归 |
| 指标与观察 | 定义Task/Trial、最终结果与过程指标；分开Trace、Metrics、Audit、Eval | 评测CSV/JSON、汇总、审计与版本记录 |
