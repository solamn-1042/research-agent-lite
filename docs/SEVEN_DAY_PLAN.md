# 七天资料调研 Agent 项目实战

2026-10-21 至 2026-10-27，北京时间。每天约 2～3 小时，持续迭代同一项目。

## 最终交付

构建个人可用的资料调研助手：输入研究问题，系统澄清范围、搜索公开资料、读取原文、检查证据缺口、按需补查，结合个人笔记生成带来源的报告。用户审阅后保存版本，可下载报告、恢复中断任务、回放公开执行记录。用固定用例验证引用、工具选择、失败恢复和重复提交。

主线为 Docker Compose：本机仅需 Docker Desktop 和代码编辑器。Python、库、测试命令、Embedding 模型与后续组件都在容器内。源代码通过目录挂载修改；报告、检查点、模型缓存和索引写入命名卷 research_data，容器路径 /app/runtime。Compose down 保留该卷；课程日常操作不使用 down -v。

项目路径：D:\Study\CodeSoft\MyProject\research-agent-lite。DeepSeek 使用已有密钥，网页开关默认关闭，开启后按 Token 计费。免费搜索可能受网络、限流和反爬影响；失败必须明确反馈。主线使用真实模型与检索；离线替身只承担工程测试，不作为模型效果证据。

## 项目参考与范围

- 主要参考：https://github.com/langchain-ai/local-deep-researcher ，2026-10-21 检索约 9.4k star。它的研究链路包括搜索、总结、发现缺口和继续检索。课程采用这一业务思路，独立实现适合入门学习的版本，并使用 DeepSeek API 降低本地硬件要求。
- 扩展参考：https://github.com/assafelovic/gpt-researcher ，本次检索约 30.2k star；完整系统规模较大，仅作后续扩展阅读。
- 能力对齐：https://javaguide.cn/ai/interview-questions/agent-project-interview-guide.html 。逐步训练业务说明、架构、取舍、故障恢复、评测和基于证据的项目讲解。
- 实际范围是本地个人应用。公开网页的读取不涉及用户鉴权；个人笔记、任务、报告仍须按工作区隔离。教学工作区标识不等同于真实登录认证。未实施的模型网关、分布式部署、多 Agent 与生产认证，应说明适用条件和当前边界。

## 关键设计约束

1. 研究范围先明确；固定节点控制输入、预算、授权和保存，模型只决定搜索词、待补查问题与证据组织。Day 6与相同证据、相同预算下的固定查询流程比较，决定Agent的收益是否成立。
2. 先单Agent。检索、正文读取、个人笔记和报告保存均有清晰工具契约。只有任务和上下文确实可独立时，才讨论多Agent。
3. 搜索摘要只用于定位。Day 1界面明确标注未读全文；Day 2后记录正文抓取成功与否、来源ID、抓取时间和版本。最终引用必须指向本次读取过的证据；不可访问或证据不足时降级说明。
4. 网页、搜索结果、个人笔记和MCP工具描述均视为外部数据。读取网页时增加允许域、请求/正文大小/类型限制、重定向与目标地址检查；不得访问内网、元数据地址、宿主机端口或本地文件。外部内容不能变更工具权限。
5. 小规模个人知识库采用轻量索引与SQLite，直接调用模型。Reranker、独立向量库、Redis、模型网关等均需有实际问题与对照证据再引入。未实现的能力按设计预案讲解。
6. 会话历史、研究State、业务报告和长期偏好分别记录。当前是否保存成功以报告表为准；下载文件由已保存版本生成，避免数据库与文件双写不一致。长期偏好仅在用户确认后保存，提供查看、删除与保留期限；未实现前不称为长期Memory。
7. 保存操作先冻结草稿内容、来源版本与参数哈希，再生成稳定actionId。同一工作区和actionId使用唯一约束；相同键不同参数拒绝。响应丢失后先查状态，不能直接生成新动作重试。
8. Day 1已有模型/工具调用次数和调度时间预算。后续补齐读取超时、上下文限额、无进展判定、共享重试预算和必要依赖不可用时的降级。调度预算和强制中断正在运行的调用应明确区分。
9. 原始密钥不进入镜像、模型上下文、Trace或课程附件。初期网页仅绑定宿主机127.0.0.1；公共部署的真实认证不纳入七天主线。
10. 所有效果数字来自实际运行，保留样本数、测试集/模型/Prompt/代码/知识版本与基线。没有用户日志时，只能标记未验收；没有生产经历时，只能展示个人项目实验和故障注入。

## 逐日自主回答机制

每天先读原理并运行最小迭代，再做1～2个不给实现答案的扩展。给出4～6道当天项目追问：学习者先用自己的代码路径、输入和运行结果作答，再查看参考要点。Day 3/5/7回访旧题并换问法。不得把“已发课程”当成“用户已完成”。

回答固定记录四项：自己的选择、约束及备选方案、已知代价、代码或实验依据。课程可给思路，不代填未测指标。第七天交付30秒、3分钟、10分钟三种介绍，以及下方清单全部问题的本人回答。

## 最终验收

- 输入“比较Docker Compose和直接在宿主机安装Python环境，优先官方资料，给出适合个人Agent项目的建议”。能澄清范围，读取证据，输出来源与限制。
- 添加个人部署笔记后，能引用笔记ID和版本；其他工作区不能读到这份笔记。
- 保存报告前可以审阅；等待确认期间重启容器可恢复；重复确认无重复版本。
- 主动注入搜索不可用、网页读取失败、恶意笔记、相似工具混淆和保存后响应丢失；记录可核验结果。
- 容器删除重建后，已保存报告、检查点、索引及模型缓存仍在；按文档导出/恢复数据。
- 交付README、架构图、30个任务、评测脚本与真实结果、两份Badcase、逐节点Trace、版本清单和项目讲解材料。
